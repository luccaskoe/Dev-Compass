# 🧭 DEV COMPASS

> Descubra seu caminho na tecnologia através de uma experiência interativa.

O **DEV COMPASS** é um projeto front-end desenvolvido para ajudar
pessoas que estão começando na programação a descobrir áreas da
tecnologia com as quais possuem maior afinidade.

A experiência combina um quiz de autodescoberta com desafios
práticos de programação, transformando o aprendizado em uma
jornada interativa.

## ✨ Funcionalidades

- Quiz de autodescoberta
- Análise de afinidades
- Gráfico de resultados
- Bússola visual de áreas
- Lobby de desafios
- Desafios de Front-End
- Desafios de Back-End
- Desafios de Engenharia de Software
- Desafios de IA
- Desafios de Segurança
- Desafios Full-Stack
- Sistema de tentativas
- Sistema de pontuação
- Feedback visual de acerto e erro
- Animações interativas
- Resultado final da sessão
- Layout responsivo

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Remix Icon
- SweetAlert2
- Google Fonts
- Intersection Observer API
- Web Audio API

## 🎯 Objetivo

O projeto foi desenvolvido como uma experiência prática de
aprendizado e exploração dentro da programação.

A proposta é transformar conceitos técnicos em desafios visuais
e interativos, permitindo que o usuário não apenas responda
perguntas, mas também visualize conceitos relacionados a cada área.

---

## 🚀 Próximos passos

O DEV COMPASS foi desenvolvido inicialmente como uma experiência
front-end.

Uma evolução futura poderá incluir:

- sistema de usuários;
- login;
- progresso salvo;
- ranking;
- histórico de desafios;
- currículo baseado nas afinidades;
- persistência de pontuação.
